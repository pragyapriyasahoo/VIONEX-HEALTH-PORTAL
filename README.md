# VIONEX Health Portal

**VIONEX does not replace human care; it bridges the gap between human interventions.**

</div>

---

## About

VIONEX Health Portal is the caregiver-facing web dashboard for **VIONEX**, an AI-powered personal care robot built for patient care. Caregivers use it to configure reminders, monitor patient interactions, and receive escalation alerts from the robot in real time.

Built around a human-in-the-loop flow: **ASSIST → UNDERSTAND → ESCALATE**.

## Features

- **Medication reminders:** caregivers set schedules, the robot delivers them
- **Routine reminders:** meals, walks, hydration and other daily tasks
- **Escalation alerts:** instant notifications when human attention is needed
- **Interaction monitoring:** conversation logs and activity history
- **Personality settings:** choose from 5 AI personalities
- **No autonomous diagnosis:** the system monitors and escalates, it never replaces medical judgment

## System Flow

```
Voice → Speech Processing → AI/LLM → Decision Engine → Response / Reminder / Caregiver Alert (Portal)
```
